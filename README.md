Collection of site mods, installable in tampermonkey

# Github widgets

[com.github.widgets.js](com.github.widgets.js) this mod add more stats aside of stars, like downloads count, commits per week, repository age.   
The goal is to replace markdown widget embeded in .md files with globally available widgets.  
<img width="781" height="44" alt="Capture d’écran 2026-07-28 à 15 21 21" src="https://github.com/user-attachments/assets/5c354ad7-7e9a-41bb-905c-6145abbddfc7" />  
Displayed stats can be configured with tampermonkey popup menu > Github Widgets Settings   
If you browse a lot github you will hit a rate limit, so in this case a token is needed.
